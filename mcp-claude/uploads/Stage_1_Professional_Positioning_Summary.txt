Q4. Modernization
Question: What data-platform or integration modernization work have you performed? What was the old approach, what changed, and why?
Answer:
I have worked on multiple projects which relate to data platform modernization work. For the marine insurance project, there were multiple old approaches. Data extraction from CRM used native Talend components and this caused slowness in data extraction, the native CRM components are now replaced by database input components which extract the data from the CRM using Tabular Data Stream and SQL endpoint, and now data can be extracted easily and faster. The sensitive database credentials were placed in Excel based configuration files and used by the Talend jobs due to which the databases were not secure, instead of the Excel configs now the Talend jobs are integrated with Azure Key Vault to dynamically fetch the credentials from them which has made the databases more secure.
